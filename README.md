# Gram10 📚

**Gram10** is an interactive English Grammar Practice Website designed specifically for Class 10 students. It helps students improve their English grammar through multiple-choice questions (MCQs), instant answer validation, and clear explanations.

The website provides an easy-to-use learning environment where students can practice grammar topics without creating an account or logging in.

## ✨ Features

- **Topic-Based Practice:** Practice individual grammar topics.
- **Randomized Questions:** Questions are shuffled for a different practice experience.
- **Multiple Difficulty Levels:** Easy, Medium, and Hard.
- **Instant Feedback:** Check answers immediately.
- **Detailed Explanations:** Understand why an answer is correct.
- **Tamil Explanations:** Additional explanations to support Tamil-speaking learners.
- **Score Tracking:** View your performance at the end of each quiz.
- **Retry Incorrect Answers:** Practice questions you answered incorrectly.
- **No Login Required:** Start learning instantly without registration.

## 📖 Grammar Topics

1. Pronouns
2. Active and Passive Voice
3. Direct and Indirect Speech
4. Idioms and Phrases

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Quiz logic, randomization, and answer validation

## 🎯 Project Goal

The main goal of Gram10 is to make English grammar learning simple, interactive, and accessible to Class 10 students through self-practice and instant explanations.

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Select a grammar topic and start practicing!
